# shopify-review-app

ReviewFlow - Complete Shopify Product Review App with Merchant Admin, Moderation, Theme App Extension, and Anti-Spam protection.

## Features
- **Merchant Admin Portal**: Dashboard with stats, review moderation (pending/approved/rejected), reply to reviews, and customizable widget settings.
- **Storefront Review Widget**: Star ratings, breakdown bars, verified badges, interactive reviews, search, and review submission modal.
- **Anti-Spam & Sentiment Engine**: Automatic detection of profanity, spam keywords, duplicate reviews, and sentiment scoring.
- **Theme App Extension**: Shopify theme app block for seamless embed.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
npm run setup # generates prisma client and seeds sample reviews
```

### Running Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the merchant admin and demo storefront sandbox.
